# Battle Royale Prototype

A lightweight browser prototype for a battle-royale game.

## Included
- Lobby
- Character selection
- Daily missions
- Multiple map zones
- Gun/loadout section
- Gloo Wall inventory and deployment
- Token economy
- Vending machine with Med Kit, Gloo Walls and Armor
- Responsive mobile/desktop UI

## Run
Open `index.html` in a browser.

## Next production steps
